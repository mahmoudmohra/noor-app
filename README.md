# تطبيق مسجد النور المبين 🕌

تطبيق مركز تحفيظ القرآن الكريم والسنة النبوية — مسجد النور المبين.
مركز معتمد من دار القرآن الكريم والسنة ووزارة الأوقاف والشؤون الدينية.

## ⬇️ تحميل التطبيق (أندرويد)

**[اضغط هنا لتحميل آخر نسخة](https://github.com/mahmoudmohra/noor-app/releases/latest/download/noor.apk)**

### طريقة التثبيت
1. اضغط على الرابط، وبينزل ملف `noor.apk`.
2. افتح الملف من التنزيلات.
3. إذا طلب إذن "تثبيت من مصادر غير معروفة"، اضغط **السماح**.
4. إذا ظهرت رسالة Google Play Protect، اضغط **Scan app** ثم **Install**.
